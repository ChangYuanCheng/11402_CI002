# UVa 11615 - Family Tree

## 題目說明

使用 Ahnentafel 編號法建立家譜樹：

- 本人編號為 1
- 父親編號 = 2 × x
- 母親編號 = 2 × x + 1

因此形成一棵完全二元樹。

共有 N 代時，家譜樹節點數為：

```text
2^N - 1
```

現在已知兩位祖先：

```text
A 與 B
```

實際上是兄弟（Brother）。

兄弟代表：

```text
他們有相同的父親與母親
```

因此原本分開的祖先分支會重疊。

要求：

```text
家譜中不同人物的總數
```

（包含自己）。

---

## 解題思路

### 完整家譜樹

N 代的完全二元樹共有：

```cpp
2^N - 1
```

個節點。

---

### 節點所在世代

利用編號可以求出節點所在深度：

```cpp
depth = floor(log2(x)) + 1
```

例如：

```text
1      → 第 1 代
2~3    → 第 2 代
4~7    → 第 3 代
8~15   → 第 4 代
```

---

### 重複的人數

假設兄弟位於第 d 代。

從他們的父母開始：

```text
第 d+1 代
```

所有祖先都會重疊。

重疊人數為：

```text
第 d+1 代到第 N 代的節點數
```

即：

```text
2 + 4 + 8 + ...
```

等比級數和：

```cpp
2^(N-d+1) - 2
```

---

### 最後答案

```cpp
答案 =
總節點數
-
重複節點數
```

即：

```cpp
(2^N - 1)
-
(2^(N-d+1) - 2)
```

其中：

```cpp
d = max(depth(A), depth(B))
```

---

## 核心公式

節點深度：

```cpp
depth = floor(log2(x)) + 1;
```

重複節點：

```cpp
duplicated = 2^(N-d+1) - 2;
```

答案：

```cpp
answer = (2^N - 1) - duplicated;
```

---

## 注意事項

### 使用 long long

因為：

```text
N ≤ 20
```

最大節點數：

```text
2^20 - 1 = 1048575
```

使用：

```cpp
long long
```

較安全。

---

### 快速計算 2^k

使用位元運算：

```cpp
1LL << k
```

例如：

```cpp
1LL << 5
```

得到：

```text
32
```

---

## 時間複雜度

只做幾次數學運算：

```text
Time: O(1)
```

```text
Space: O(1)
```

## 測資範例

### 輸入

```text
3
4 4 12
4 4 6
5 2 3
```

### 輸出

```text
15
13
17
```

---

## 範例分析

### Case 1

```text
N = 4
A = 4
B = 12
```

較深節點位於：

```text
第 4 代
```

已經沒有父母節點存在於樹中。

因此：

```text
沒有重疊
```

答案：

```text
15
```

---

### Case 2

```text
N = 4
A = 4
B = 6
```

位於第 3 代。

重疊祖先：

```text
第 4 代
```

共有：

```text
2 人
```

因此：

```text
15 - 2 = 13
```

---

### Case 3

```text
N = 5
A = 2
B = 3
```

位於第 2 代。

重疊祖先：

```text
第 3~5 代
```

共有：

```text
2 + 4 + 8 = 14 人
```

因此：

```text
31 - 14 = 17
```
