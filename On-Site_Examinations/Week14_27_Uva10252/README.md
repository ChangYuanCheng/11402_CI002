# UVa 10252 - Common Permutation

## 題目說明

給定兩個只包含小寫英文字母的字串。

請找出兩個字串共同擁有的字母，並依照字母順序輸出。

若某個字母在兩個字串中都出現多次，則輸出的次數應為兩者出現次數的較小值。

---

## 解題思路

觀察題目可知：

- 字母只有 `a ~ z`
- 需要找出兩個字串共同出現的字母
- 若重複出現，需保留共同次數

因此可以使用兩個計數陣列：

1. `cntA[26]` 記錄第一個字串每個字母出現次數
2. `cntB[26]` 記錄第二個字串每個字母出現次數
3. 對於每個字母：
   - 共同出現次數 = `min(cntA[i], cntB[i])`
4. 按照 `a → z` 順序輸出即可

---

## 注意事項

- 輸入直到 EOF 結束
- 每筆測資由兩行字串組成
- 字串可能包含重複字母
- 必須依照字母順序輸出
- 使用 `getline()` 讀取整行輸入

---

## 時間複雜度

- Time: O(n + m)
- Space: O(1)

其中：

- n = 第一個字串長度
- m = 第二個字串長度

因為字母種類固定只有 26 個。

## 測資範例

### 輸入

```text

```

### 輸出


## 核心觀念

例如：

```text
abcd
bcdd
```

統計結果：

| 字母 | 第一串 | 第二串 | 共同次數 |
|------|--------|--------|---------|
| a | 1 | 0 | 0 |
| b | 1 | 1 | 1 |
| c | 1 | 1 | 1 |
| d | 1 | 2 | 1 |

因此輸出：

```text
bcd
```

因為：

```cpp
min(1,1)=1
min(1,1)=1
min(1,2)=1
```

只保留兩個字串都擁有的字母數量。
