# UVa 10041 - Vito's Family

## 題目說明

Vito 想要選擇一條街上的某個位置作為家庭聚會地點。

已知所有親戚居住的門牌號碼，要求找到一個位置，使得所有親戚到該位置的距離總和最小。

距離定義為：

```text
|a - b|
```

其中：

- a 為親戚住址
- b 為聚會地點

求最小總距離。

---

## 解題思路

對於一群數字：

```text
x1, x2, x3, ..., xn
```

若要最小化：

```text
|x1-p| + |x2-p| + ... + |xn-p|
```

最佳解一定是：

```text
中位數 (Median)
```

因此解法如下：

1. 讀入所有親戚住址
2. 將住址排序
3. 找出中位數
4. 計算所有住址到中位數的距離總和
5. 輸出答案

---

## 為什麼是中位數？

假設住址：

```text
1 2 3 100
```

若選：

```text
2
```

距離總和：

```text
1 + 0 + 1 + 98 = 100
```

若選：

```text
3
```

距離總和：

```text
2 + 1 + 0 + 97 = 100
```

若選：

```text
50
```

距離總和：

```text
49 + 48 + 47 + 50 = 194
```

可以發現：

中位數附近會使總距離最小。

---

## 注意事項

- 親戚數量最多只有 500
- 排序後直接取中位數即可
- 若有兩個中位數，取任意一個都會得到相同答案

例如：

```text
1 2 3 4
```

中位數區間：

```text
2 ~ 3
```

選 2 或 3 結果都相同。

---

## 時間複雜度

排序：

```text
O(r log r)
```

計算距離：

```text
O(r)
```

總計：

```text
O(r log r)
```

## 核心觀念

排序後：

```cpp
sort(a.begin(), a.end());
```

中位數位置：

```cpp
a[r / 2]
```

計算答案：

```cpp
ans += abs(a[i] - median);
```

因為：

```text
Median 能最小化
Σ |xi - p|
```
