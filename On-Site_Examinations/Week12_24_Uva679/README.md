# UVa 679 - Dropping Balls

## 題目說明

有一棵完全二元樹。

每個內部節點都有一個開關：

- 初始狀態為 Left
- 球經過後，開關會翻轉
- 若開關為 Left，球往左走
- 若開關為 Right，球往右走

現在依序放入第 1 顆、第 2 顆、...、第 I 顆球。

求：

```text
第 I 顆球最後停在哪個葉節點
```

---

## 樹的編號方式

```text
          1
        /   \
       2     3
      / \   / \
     4  5  6   7
```

規則：

```text
左兒子 = 2 × x
右兒子 = 2 × x + 1
```

---

## 解題思路

### 關鍵觀察

不需要真的模擬前面所有球。

只要考慮：

```text
第 I 顆球
```

在每一層會往哪裡走即可。

---

### 奇數球

若：

```cpp
I % 2 == 1
```

表示往左走。

例如：

```text
第1顆
第3顆
第5顆
```

走左邊。

更新：

```cpp
I = (I + 1) / 2;
```

---

### 偶數球

若：

```cpp
I % 2 == 0
```

表示往右走。

例如：

```text
第2顆
第4顆
第6顆
```

走右邊。

更新：

```cpp
I = I / 2;
```

---

### 節點編號更新

往左：

```cpp
node = node * 2;
```

往右：

```cpp
node = node * 2 + 1;
```

---

## 範例分析

### 輸入

```text
D = 4
I = 2
```

起點：

```text
node = 1
```

---

第一層：

```text
I = 2 (偶數)
```

往右：

```text
node = 3
I = 1
```

---

第二層：

```text
I = 1 (奇數)
```

往左：

```text
node = 6
I = 1
```

---

第三層：

```text
I = 1 (奇數)
```

往左：

```text
node = 12
```

答案：

```text
12
```

---

## 為什麼不用模擬所有球？

假設：

```text
I = 1000000
```

若逐顆模擬：

```text
O(I × D)
```

太慢。

---

利用規律：

```text
奇數往左
偶數往右
```

只需走樹高：

```text
D-1 層
```

即可。

---

## 時間複雜度

樹高：

```text
D ≤ 20
```

每層處理一次：

```text
Time: O(D)
```

```text
Space: O(1)
```

## 核心觀念

每一層：

```cpp
if (I % 2 == 1)
{
    node = node * 2;
    I = (I + 1) / 2;
}
else
{
    node = node * 2 + 1;
    I = I / 2;
}
```

利用：

```text
奇數 → 左
偶數 → 右
```

直接求出第 I 顆球的路徑。

這是 UVa 679 最重要的技巧。
