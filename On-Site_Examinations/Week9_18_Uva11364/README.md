# UVa 11364 - Parking

## 題目說明

Sam 要到一條街上的多家商店購物。

街道上的店面位置以整數表示。

例如：

```text
2 4 6
```

表示三家商店位於：

```text
2、4、6
```

的位置。

Sam 可以把車停在任何位置。

要求：

```text
找出最少需要走的總距離
```

其中：

```text
從停車位置走到所有商店
最後再回到車子
```

的總距離最小。

---

## 解題思路

### 關鍵觀察

Sam 必須拜訪：

```text
最左邊商店
到
最右邊商店
```

之間的所有商店。

因此：

```text
一定會走過
[min , max]
```

這段區間。

---

### 最佳停車方式

不論車停在哪裡，

最後一定要：

```text
從車走到商店區間
再回到車
```

因此答案只和：

```text
最左商店
最右商店
```

有關。

---

### 總距離

設：

```text
L = 最左位置
R = 最右位置
```

區間長度：

```text
R - L
```

因為：

```text
要來回一次
```

所以：

```text
答案 = 2 × (R - L)
```

---

## 範例分析

### 輸入

```text
4
24 13 89 37
```

排序後：

```text
13 24 37 89
```

---

最左：

```text
13
```

最右：

```text
89
```

---

距離：

```text
89 - 13 = 76
```

來回：

```text
76 × 2 = 152
```

答案：

```text
152
```

---

## 為什麼只看最大最小？

假設：

```text
1 2 4 10
```

商店位置。

---

不管怎麼停：

都必須拜訪：

```text
1
```

以及：

```text
10
```

---

因此一定會走完整段：

```text
10 - 1
```

---

最後回到車：

```text
再走一次
```

所以：

```text
2 × (10 - 1)
```

---

## 程式碼講解

### 讀入商店數量

```cpp
int n;
cin >> n;
```

---

### 儲存位置

```cpp
vector<int> store(n);
```

---

### 讀入資料

```cpp
for(int i=0;i<n;i++)
{
    cin >> store[i];
}
```

---

### 排序

```cpp
sort(store.begin(), store.end());
```

例如：

```text
24 13 89 37
```

變成：

```text
13 24 37 89
```

---

### 計算答案

最小值：

```cpp
store[0]
```

最大值：

```cpp
store[n-1]
```

區間長度：

```cpp
store[n-1] - store[0]
```

來回：

```cpp
2 * (store[n-1] - store[0])
```

---

## 時間複雜度

排序：

```text
O(n log n)
```

其餘操作：

```text
O(1)
```

總計：

```text
O(n log n)
```

---

## 更快做法

其實不需要排序。

直接記錄：

```cpp
minPos
maxPos
```

即可。

```cpp
answer = 2 * (maxPos - minPos);
```

時間：

```text
O(n)
```

## 核心觀念

只要找到：

```text
最左商店
最右商店
```

答案就是：

```cpp
2 * (maxPos - minPos)
```

因為一定要走完整個區間一次，

並回到停車位置一次。

這題是 UVa 最經典的 Observation（觀察題）之一。
