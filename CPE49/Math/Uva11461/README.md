# UVa 11461 - Square Numbers

##  題目說明
給定兩個整數 `a` 和 `b`，需要計算在區間 `[a, b]` 之間有多少個「完全平方數」。

完全平方數定義：
- 形如 `x = k^2` 的數

---

##  解題思路
1. 讀入 `a` 和 `b`
2. 若 `a == 0 && b == 0` → 結束
3. 找出：
   - 最小平方根：`ceil(sqrt(a))`
   - 最大平方根：`floor(sqrt(b))`
4. 答案為：

max(0, floor(sqrt(b)) - ceil(sqrt(a)) + 1)


---

##  注意事項
- 要用 `sqrt`
- 注意浮點誤差（建議轉 int 修正）
- 多組測資直到 0 0

---

##  時間複雜度
- Time: O(1)
- Space: O(1)

---

##  測資範例

1 4
3 9
17 24
0 0


### 輸出

2
2
0
