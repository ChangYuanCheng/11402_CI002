# UVa 10056 - What is the Probability?

##  題目說明
有一個遊戲：每一位玩家依序輪流擲骰子（成功機率為 `p`），每次擲骰子成功的人會獲勝。

已知：
- 有 `n` 個玩家
- 每個玩家依序輪流擲骰
- 第 `i` 位玩家在第 `i, i+n, i+2n ...` 次才會輪到
- 成功機率為 `p`

求第 `i` 位玩家獲勝的機率。

---

##  解題思路
1. 讀入 `t` 組測資
2. 每組輸入：
   - 玩家數 `n`
   - 成功機率 `p`
   - 玩家編號 `i`
3. 分析：
   - 第 i 個玩家在第 i 次成功的機率：
     ```
     p * (1 - p)^(i - 1)
     ```
   - 每隔 n 次輪到一次，所以變成：
     ```
     p * (1 - p)^(i - 1) / (1 - (1 - p)^n)
     ```
4. 輸出答案

---

##  注意事項
- 若 p = 0 → 答案為 0
- 使用 double 計算
- 要注意精度輸出

---

##  時間複雜度
- Time: O(1)
- Space: O(1)

---

##  測資範例

1
2 0.5 1


### 輸出

0.6667
