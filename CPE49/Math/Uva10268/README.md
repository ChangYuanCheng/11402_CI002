# UVa 10268 - 498-bis

##  題目說明
給定一個多項式：

f(x) = a1x^n + a2x^(n-1) + ... + an*x + a(n+1)


以及一個 x 值，需要計算：
- f(x)
- f'(x)（導數）

輸入：
- 第一行為係數（多項式）
- 第二行為 x 值

---

##  解題思路
1. 讀入一整行係數
2. 讀入 x
3. 對多項式計算：
   - f(x)：逐項累加
   - f'(x)：使用導數公式
4. 輸出 f(x)

（注意：本題只要求 f(x)，不是 f'(x)）

---

##  計算方式
假設係數為：

a0, a1, a2 ... an


則：

f(x) = a0x^n + a1x^(n-1) + ... + an


---

##  注意事項
- 係數可能有負數
- 使用 long long 或 double
- 要處理空白輸入
- 只需輸出 f(x)

---

##  時間複雜度
- Time: O(n)
- Space: O(n)

---

##  測資範例

1 2 3
5


### 輸出

38
