# UVa 10812 - Beat the Spread!

##  題目說明
給定兩個數字：
- `s`：兩隊分數總和
- `d`：兩隊分數差

需要求出兩隊實際得分：
- A = 較高分
- B = 較低分

---

##  解題思路
1. 設兩隊分數為：
   - A（大）
   - B（小）
2. 根據題目：

A + B = s
A - B = d

3. 聯立方程式解：
- A = (s + d) / 2
- B = (s - d) / 2
4. 若結果不為整數或 B < 0：
- 輸出 "impossible"

---

##  注意事項
- 要檢查是否整除（(s + d) 必須為偶數）
- B 不能為負數
- 多組測資

---

##  時間複雜度
- Time: O(1)
- Space: O(1)

---

##  測資範例

40 20-
20 40


### 輸出

30 10
impossible
