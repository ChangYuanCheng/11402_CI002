# UVa 11349 - Symmetric Matrix

## 題目說明
給定一個 `n × n` 的矩陣，判斷它是否為「對稱矩陣」。

對稱矩陣定義：

M[i][j] == M[n-1-i][n-1-j]

也就是矩陣以中心旋轉 180 度後仍然相同。

另外：
- 所有元素必須為非負數
- 若出現負數，直接判定為 `Non-symmetric`

---

## 解題思路

1. 讀入測資數 `T`
2. 每組測資：
   - 讀入矩陣大小 `n`
   - 讀入 `n × n` 矩陣
3. 檢查：
   - 元素是否為非負數
   - `M[i][j]` 是否等於 `M[n-1-i][n-1-j]`
4. 若全部符合：
   - `Symmetric`
5. 否則：
   - `Non-symmetric`
