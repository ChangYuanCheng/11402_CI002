# UVa 10038 - Jolly Jumpers

##  題目說明
給定一個長度為 `n` 的整數序列，判斷它是否為「Jolly Jumper」。

定義如下：
- 對於一個長度為 n 的序列
- 需要包含所有差值：
  `1 ~ n-1`
- 每個相鄰差的絕對值必須「剛好出現一次」

---

##  解題思路
1. 讀入 n 與序列
2. 計算所有相鄰元素的差值：
   - `abs(a[i] - a[i+1])`
3. 使用 bool 陣列標記差值是否出現
4. 檢查：
   - 是否所有 `1 ~ n-1` 都出現
5. 若完整 → Jolly
   否則 → Not jolly

---

##  注意事項
- 差值範圍是 `1 ~ n-1`
- n = 1 時一定是 Jolly
- 使用 bool array 記錄即可

---

##  時間複雜度
- Time: O(n)
- Space: O(n)

---

##  測資範例

4 1 4 2 3
5 1 4 2 -1 6


### 輸出

Jolly
Not jolly
