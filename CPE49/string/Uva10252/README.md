# UVa 10252 - Common Permutation

##  題目說明
給定兩個字串 `a` 和 `b`，需要找出它們的「共同字母」（common permutation）。

規則如下：
- 每個字母只取「同時出現在兩字串中的最小次數」
- 輸出需依字母順序（a → z）
- 不考慮大小寫以外的字元（本題只有小寫英文字母）

---

##  解題思路
1. 讀入兩個字串 `a`、`b`
2. 統計兩個字串各自每個字母出現次數
3. 對 a~z：
   - 取 min(cntA[i], cntB[i])
   - 輸出對應次數的字母
4. 重複直到 EOF

---

##  注意事項
- 只處理小寫字母 `a ~ z`
- 輸出需依字典序
- 每組測資獨立輸出一行
- 使用陣列計數即可（26 個）

---

##  時間複雜度
- Time: O(n)
- Space: O(1)
