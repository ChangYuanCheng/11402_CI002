# UVa 11332 - Summing Digits

##  題目說明
給定一個整數 `n`，需要不斷將其各位數相加，直到結果變成一位數為止。

例如：
- 9875 → 9 + 8 + 7 + 5 = 29  
- 29 → 2 + 9 = 11  
- 11 → 1 + 1 = 2  

最後輸出結果 `2`

---

##  解題思路
1. 讀入整數 `n`
2. 當 `n != 0` 時持續處理：
   - 不斷將各位數相加
   - 若結果 >= 10，繼續拆解
3. 直到變成一位數
4. 輸出結果

---

##  注意事項
- 輸入可能為 0（直接輸出 0）
- 每次都要重新計算 digit sum
- 可用循環或遞迴模擬

---

##  時間複雜度
- Time: O(log n)
- Space: O(1)
