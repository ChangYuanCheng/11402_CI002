# UVa 10008 - What's Cryptanalysis?

## 題目說明
給定多行英文文字，統計每個英文字母出現的次數。

規則：
- 不分大小寫
- 只統計英文字母 `A ~ Z`
- 依照出現次數由大到小排序
- 若次數相同，依字母字典序排序

---

## 解題思路

1. 讀入測資數 `n`
2. 使用 `getline()` 讀入每一行文字
3. 掃描每個字元：
   - 若為英文字母：
     - 轉成大寫
     - 統計次數
4. 將所有字母與次數存入陣列
5. 排序：
   - 次數大的優先
   - 若次數相同，字母小的優先
6. 輸出所有出現過的字母

---

## 注意事項

- 必須忽略大小寫
- 只統計英文字母
- 可使用 `toupper()`
- 排序規則：
  - 次數遞減
  - 字母遞增

---

## 時間複雜度

- Time Complexity: `O(n)`
- Space Complexity: `O(1)`

其中：
- `n` = 所有字元總數

---

## 測資範例

### Input

```txt
3
This is a test.
Count me 1 2 3.
Wow!!!
```

### Output

```txt
T 4
S 3
O 3
I 2
W 2
...
```
