# UVa 10222 - Decode the Mad man

##  題目說明
給定一段英文輸入，需將每個字元「往左移一格鍵盤位置」還原成原本輸入的字。

也就是：
- 輸入是「錯誤輸入（右邊按到的鍵）」
- 需要還原成正常鍵盤輸入

鍵盤對應如下（QWERTY）：

`1234567890-=
QWERTYUIOP[]
ASDFGHJKL;'
ZXCVBNM,./


規則：
- 每個字元輸出它「左邊一個鍵」
- 空白 그대로輸出

---

##  解題思路
1. 建立鍵盤字串對應表
2. 讀入整行字串
3. 對每個字元：
   - 如果是空白 → 直接輸出
   - 否則找在鍵盤上的位置
   - 輸出左邊一個字元
4. 重複直到 EOF

---

##  注意事項
- 使用 `getline` 讀整行
- 要處理特殊符號（`, . / ; ' [ ]`）
- 空白不能忽略

---

##  時間複雜度
- Time: O(n)
- Space: O(1)

---

##  測資範例

O S, GOMR YPFSU/


### 輸出

I AM FINE TODAY.
