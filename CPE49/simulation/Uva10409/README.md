# UVa 10409 - Die Game

##  題目說明
有一顆骰子（dice），初始狀態固定。給定一連串指令，骰子會依照指令翻轉，最後輸出「頂面」的數字。

指令如下：
- `north`：向北翻
- `south`：向南翻
- `east`：向東翻
- `west`：向西翻

---

##  解題思路
1. 初始化骰子六個面：
   - top（上）
   - bottom（下）
   - north（北）
   - south（南）
   - east（東）
   - west（西）
2. 依序讀入指令
3. 每個指令更新骰子六個面的對應關係
4. 最後輸出 top 面

---

##  注意事項
- 每次翻轉都是「整顆骰子狀態改變」
- 必須同步更新 6 個面
- 多組測資，直到輸入 0

---

##  時間複雜度
- Time: O(n)
- Space: O(1)

---

##  測資範例

3
north
east
south
0


### 輸出

1
