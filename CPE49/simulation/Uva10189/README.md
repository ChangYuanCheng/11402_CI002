# UVa 10189 - Minesweeper

##  題目說明
給定一個地雷版圖（M × N），需要輸出每個空格周圍 8 個方向的地雷數量。

規則如下：
- `*` 表示地雷
- `.` 表示空格
- 每個 `.` 要變成周圍地雷數字
- `*` 保持不變

---

##  解題思路
1. 讀入地圖大小 `n, m`
2. 建立二維陣列存地圖
3. 建立結果陣列
4. 對每個格子：
   - 若是 `*` → 直接輸出 `*`
   - 若是 `.` → 掃描 8 個方向統計地雷數
5. 輸出結果地圖

---

##  注意事項
- 要檢查 8 個方向（上下左右 + 四個斜角）
- 注意邊界不能越界
- 每組測資之間要輸出空行
- 多組輸入直到 n = m = 0

---

##  時間複雜度
- Time: O(n × m × 8)
- Space: O(n × m)

---

##  測資範例

4 4
...
....
...
....
0 0


### 輸出

100
2210
110
1110
