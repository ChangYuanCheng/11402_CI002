# UVa 10415 - Eb Alto Saxophone Player

##  題目說明
給定一段音符字串，需要計算每個手指在演奏過程中「按下的次數」。

音符包含：
`c d e f g a b C D E F G A B`

每個音符對應一組需要按下的手指。

---

##  解題思路
1. 建立每個音符對應的「按鍵狀態」
   - 用 10 個手指（0~9）表示
   - 每個音符對應一個 10-bit 狀態
2. 初始化：
   - 所有手指狀態 = 0
3. 讀入音符字串
4. 對每個音符：
   - 比較「上一個狀態」與「當前狀態」
   - 若從 0 → 1，表示該手指被按下 → 次數 +1
5. 更新狀態
6. 輸出每個手指的總按壓次數

---

##  注意事項
- 要紀錄「上一個音符狀態」
- 只有 0→1 才算按下次數
- 使用固定 mapping 表

---

##  時間複雜度
- Time: O(n)
- Space: O(1)

---

##  測資範例

cdefgab
