# UVa 118 - Mutant Flatworld Explorers

##  題目說明
在一個二維平面上，有一個機器人會依照指令移動。機器人從指定起點開始，面向某個方向（N, E, S, W），並依照指令行動。

指令包含：
- `L`：向左轉 90 度（不移動）
- `R`：向右轉 90 度（不移動）
- `F`：往前移動一步（依當前方向）

如果機器人走出地圖邊界：
- 該指令會被忽略
- 並在該格留下「scent」（標記）
- 未來其他機器人如果走到同樣位置並會掉出界，就會忽略該指令

---

##  解題思路
1. 讀入地圖大小 `maxX, maxY`
2. 重複讀入每個機器人資料：
   - 起始座標 `x, y`
   - 起始方向 `dir`
   - 指令字串
3. 依序執行指令：
   - `L / R` → 轉向
   - `F` → 嘗試移動
4. 若移動會出界：
   - 若該格已有 scent → 忽略
   - 否則記錄 scent 並停止該步移動
5. 輸出最終位置與方向

---

##  注意事項
- 方向需用陣列或 enum 管理
- scent 需用 2D boolean 記錄
- 出界才會標記 scent
- 多組機器人依序處理

---

##  時間複雜度
- Time: O(n × m)
- Space: O(地圖大小)

---

##  測資範例

5 3
1 1 E
RFRFRFRF
3 2 N
FRRFLLFFRRFLL
