# UVa 10420 - List of Conquests

##  題目說明
給定多行國家名稱與人名（國家 + 姓名），需要統計每個國家出現的次數（人數），並依照國家字典序輸出結果。

輸入格式：
- 每行第一個字是國家名稱
- 後面是人名（可忽略）

---

##  解題思路
1. 使用 map 統計每個國家的出現次數
2. 每讀一行：
   - 取第一個字串（國家名）
   - 次數 +1
3. 輸入結束後：
   - 依字典序輸出 map
4. 輸出格式為：
   - 國家名稱 + 人數

---

##  注意事項
- 國家名稱是第一個單字
- 人名可忽略
- 使用 map 會自動排序（字典序）
- 輸入直到 EOF

---

##  時間複雜度
- Time: O(n log n)
- Space: O(n)

---

##  測資範例

Canada John
Canada Alice
Brazil Maria


### 輸出

Brazil 1
Canada 2
