# UVa 10101 - Bangla Numbers

##  題目說明
給定一個非常大的整數，需要將其轉換成「Bangla 數字格式」輸出。

Bangla 分組規則如下：
- 從右到左，每 2 位數一組
- 第一組（最右邊）為 2 位
- 接著依序為：kuti（10^7）、lakh（10^5）、hajar（10^3）、shata（10^2）等單位

輸出時需要依照單位轉換成對應格式。

---

##  解題思路
1. 讀入字串形式的大數（避免溢位）
2. 從右側開始分段：
   - 2 位（最後一組）
   - 接著 2 位（hajar）
   - 接著 2 位（lakh）
   - 接著 2 位（kuti）
   - 依序遞迴處理更高位數
3. 每一段依規則輸出對應單位名稱
4. 注意處理 0 的情況

---

##  注意事項
- 必須使用字串處理
- 每組測資前要輸出編號
- 連續 0 不輸出任何單位
- 輸出格式需嚴格遵守空格規則

---

##  時間複雜度
- Time: O(n)
- Space: O(n)

---

##  測資範例

23764
45897458973958
0
