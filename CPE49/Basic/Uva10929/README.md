# UVa 10929 - You can say 11

##  題目說明
給定一個很大的整數（以字串形式輸入），判斷該數字是否為 11 的倍數。

規則如下：
- 若該數字能被 11 整除 → 輸出 `"is a multiple of 11"`
- 否則 → 輸出 `"is not a multiple of 11"`

---

##  解題思路
1. 使用字串讀入數字（避免超出整數範圍）
2. 使用 11 的特性判斷：
   - 奇數位數字總和 - 偶數位數字總和
3. 若結果為 0 或 11 的倍數 → 為 11 的倍數
4. 重複直到輸入為 `"0"`

---

##  注意事項
- 數字可能非常大，不能用 int/long long
- 必須使用字串處理
- 輸入以 `"0"` 結束

---

##  時間複雜度
- Time: O(n)
- Space: O(1)

---

##  測資範例

112233
30800
2937
0


### 輸出

112233 is a multiple of 11.
30800 is a multiple of 11.
2937 is not a multiple of 11.
