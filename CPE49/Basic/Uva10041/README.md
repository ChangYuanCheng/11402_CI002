# UVa 10041 - Vito’s Family

> 📄 **Original Problem PDF:**  
> https://onlinejudge.org/external/100/10041.pdf

## 題目說明
給定一組親戚的住址（整數），需要找出一個位置，使得所有親戚到該位置的距離總和最小。

規則如下：
- 距離定義為兩個整數之差的絕對值 `|a - b|`
- 選擇一個位置，使所有距離加總最小

---

## 解題思路
1. 讀入測資數 `t`
2. 每組測資：
   - 讀入親戚數量 `n`
   - 讀入 `n` 個住址
3. 將所有住址排序
4. 找出中位數（median）：
   - 取 `a[n / 2]`
5. 對所有住址計算與中位數的距離總和
6. 輸出最小距離總和

---

## 注意事項
- 一定要先排序
- 若 `n` 為偶數，取任一中位數皆可
- 不可使用平均數（會得到錯誤答案）
- 輸出的是距離總和，不是位置

---

## 時間複雜度
- Time: **O(n log n)**
- Space: **O(n)**
