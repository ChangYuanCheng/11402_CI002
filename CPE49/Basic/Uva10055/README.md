# UVa 10055 - Hashmat the Brave Warrior

##  題目說明
給定兩個整數 `a` 和 `b`，分別代表兩個軍隊的人數，需要計算兩者之間的人數差。

規則如下：
- 計算兩數的差的絕對值 `|a - b|`
- 每一行輸入對應一組測資

---

##  解題思路
1. 使用 `while(cin >> a >> b)` 讀入多筆測資
2. 對每組資料：
   - 計算 `|a - b|`
3. 輸出結果

---

##  注意事項
- 輸入可能非常大，需使用 `long long`
- 測資為多筆，直到 EOF
- 輸出為兩數差的絕對值

---

##  時間複雜度
- Time: O(1)
- Space: O(1)
