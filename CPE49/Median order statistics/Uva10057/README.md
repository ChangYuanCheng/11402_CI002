# UVa 10057 - A mid-summer night's dream

##  題目說明
給定一組整數，要求找出「最佳中位數相關解」並計算最小距離。

具體來說：
- 找出所有數字的「中位數」
- 計算所有數字到中位數的絕對距離總和
- 同時要考慮「中位數可能有多個解」（偶數情況）

---

##  解題思路
1. 讀入所有數字並存入陣列
2. 對陣列排序
3. 找出中位數位置：
   - 若 n 為奇數：只有一個中位數
   - 若 n 為偶數：中間兩個都可作為最佳解
4. 計算：
   - 第一個答案：使用 a[n/2]
   - 第二個答案：使用 a[n/2 - 1]
5. 計算中位數區間：
   - lower bound（左側有幾個數）
   - upper bound（右側有幾個數）
6. 輸出：
   - 中位數可能的個數
   - 最小距離範圍（兩端值）

---

##  注意事項
- 一定要排序
- 偶數情況要輸出「區間」
- 使用 long long 避免溢位
- 要處理重複元素

---

##  時間複雜度
- Time: O(n log n)
- Space: O(n)

---

##  測資範例

4
1
2
2
4


### 輸出

2 2 2
